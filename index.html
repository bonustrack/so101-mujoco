How the loop works

Jev takes the target: the selected object, or the first box. Code turns the scene into plain facts, with the target's type and size. Jev is a decision model, not a chat model: it picks the next of 7 commands, with a probability for each. Code solves the joint angles (IK) and MuJoCo moves the arm. Code checks success: target 5 cm up, held for 1 s. At most 12 turns.

The key stays in this browser. Calls go through this site's Netlify Function, because TypeSafe blocks browser calls. It passes the key on and never stores or logs it.
